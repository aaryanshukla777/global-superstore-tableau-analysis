# Global Superstore Analysis — Tableau

## Overview
This project uses the Global Superstore dataset to explore sales and profitability across regions, product categories, customer segments, and countries.

## Analysis
The Tableau workbook includes visualisations covering:
- Sales by region and customer segment
- Profit by category and sub-category
- Profit margin by country
- Top 10 countries by sales

## Tools Used
- Tableau
- Excel

## Files
- `Global Superstore Analysis.twb` — Tableau workbook
- `Global Superstore (1).xls` — dataset used for the analysis

## How to View
Download the workbook and dataset, then open the workbook in Tableau. If the data connection is broken, reconnect it to the downloaded dataset.
